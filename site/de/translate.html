Übersetzungsanleitung

SysWatch übersetzen

SysWatch spricht Englisch, Deutsch, Französisch, Spanisch und Russisch, auf dem Handy und unter Windows. Du kannst deine Sprache hinzufügen oder eine Formulierung in einer vorhandenen verbessern. Programmieren musst du nicht: Jede Sprache ist eine Textdatei.

Sobald eine Übersetzung angenommen ist, holt sich jede SysWatch-App sie von selbst, innerhalb eines Tages oder sofort über Einstellungen, Sprache, Jetzt prüfen. Ein App-Update ist nicht nötig.

Deine Sprache hinzufügen

  1. Forke das SysWatch-Repository auf GitHub (die Schaltfläche Fork oben rechts auf der GitHub-Seite).

  2. Kopiere im Ordner translations die Datei en.xml und benenne die Kopie nach deinem Sprachcode: hi.xml für Hindi, pt-BR.xml für brasilianisches Portugiesisch, ja.xml für Japanisch. Die Liste der Sprachcodes führt sie in der ersten Spalte.

  3. Übersetze den Text zwischen den Tags. Alles innerhalb der Klammern < > bleibt, wie es ist.

    <!-- English -->
<string name="pair_scan">Scan the code on your PC</string>

<!-- Your file -->
<string name="pair_scan">अपने पीसी पर कोड स्कैन करें</string>

  4. Öffne einen Pull Request. Eine Prüfung läuft von selbst und sagt dir in klaren Worten, ob etwas zu korrigieren ist. Sobald sie grün ist, wird die Übersetzung geprüft und übernommen.

Du musst nicht alles auf einmal fertig machen. Texte, die du weglässt, erscheinen auf Englisch, und die App zeigt, wie vollständig eine Sprache ist. Lass aber keinen Text leer: Lösche dann lieber die ganze Zeile.

Eine Datei gilt für beide Apps. Texte, deren Name mit desktop_ beginnt, gehören zur Windows-App, alle anderen zur Handy-App.

Eine vorhandene Übersetzung verbessern

Bearbeite die Datei der Sprache (de.xml, fr.xml, es.xml, ru.xml), ändere den Text und öffne einen Pull Request. Schreib in einem Satz, warum die neue Formulierung besser ist.

Die Regeln, alle fünf

1. Platzhalter behalten

Dinge wie %1$s und %2$d sind Lücken, die die App füllt (ein Name, eine Zahl). Jeder Platzhalter aus dem Englischen muss in deinem Text vorkommen. Du darfst ihn dorthin verschieben, wo deine Grammatik ihn braucht: Dafür sind sie nummeriert.

<string name="settings_paired_with">Paired with code %1$s</string>
<string name="settings_paired_with">Gekoppelt mit Code %1$s</string>

Ein echtes Prozentzeichen neben Platzhaltern wird doppelt geschrieben: %1$d%% erscheint als 47%.

2. Vor einen Apostroph gehört ein Backslash

l\'application, nicht l'application. Schreib &amp; für & und &lt; für <.

3. Namen und Einheiten nicht übersetzen

SysWatch, DevLune, CPU, GPU, RAM, Wi-Fi, Tailscale, Google Play, Windows, Android und Einheiten wie MB, GB, GHz, °C bleiben, wie sie sind. Auch die Kunst-Zifferblätter (Horizon, Blocks, Bauhaus, Ink, Weave, Bloom, Type, Pixel) behalten ihre Namen.

4. Pluralformen folgen deiner Sprache

Englisch hat zwei Formen, one und other. Hat deine Sprache mehr (Russisch, Polnisch, Arabisch…), füge die Formen hinzu, die sie braucht:

<plurals name="settings_import_done">
    <item quantity="one">Импортировано %1$d правило.</item>
    <item quantity="few">Импортировано %1$d правила.</item>
    <item quantity="many">Импортировано %1$d правил.</item>
    <item quantity="other">Импортировано %1$d правила.</item>
</plurals>

5. Kurz und schlicht bleiben

Dieser Text steht auf Schaltflächen und kleinen Karten auf einem Handy. Nimm das Wort, das die Leute wirklich benutzen, statt des förmlichen. Keine langen Gedankenstriche: Nimm ein Komma, einen Doppelpunkt oder einen Punkt.

Die Zeilen, die in en.xml mit <!-- beginnen, sind Hinweise für dich: was eine Lücke enthält oder wo der Text erscheint. In deiner Datei musst du sie nicht behalten.

Ein Text ist besonders: language_name ist der Name deiner Sprache, in deiner Sprache geschrieben (Deutsch, Español, Русский, हिन्दी). So erscheint sie in der Sprachliste der App.

Die Datei vor dem Senden prüfen

Dieser Schritt ist freiwillig. Wenn du Python hast, führe im Ordner des Repositorys aus:

python scripts/translations.py check translations

Das gibt ok aus oder genau die Texte, die du korrigieren musst. Dieselbe Prüfung läuft bei deinem Pull Request.

Was nach der Übernahme passiert

  • languages.json im Ordner translations wird automatisch aktualisiert. Diese Liste liest die App.
  • Die Apps sehen einmal am Tag nach. Ein Handy, das deine Sprache nutzt, lädt die neue Datei, prüft jeden Text auf dem Gerät noch einmal (ein fehlerhafter Text wird übersprungen und auf Englisch gezeigt, ein Fehler kann die App also nie kaputt machen), speichert sie und zeigt sie an.
  • Sprachen, die nicht in die App eingebaut sind, erscheinen in der Sprachliste mit einem Download-Zeichen. Beliebte Sprachen werden mit der nächsten App-Version eingebaut.

Fragen

Eröffne ein Issue auf GitHub oder frag auf Discord. Danke, dass du hilfst, SysWatch in die Sprache der Leute zu bringen.
