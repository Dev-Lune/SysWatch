Install guide

Install SysWatch and pair your phone

SysWatch has two parts: the desktop app on the PC you want to watch, and the Android app on your phone. Install the desktop app first, then pair the phone.

Download the desktop app

SysWatch runs on Windows 10 and Windows 11, 64-bit. The installer is SysWatch_0.2.1_x64-setup.exe, about 3.5 MB. The phone app needs Android 7.0 or newer.

Download for Windows Get it on Google Play

Every version and its release notes are on the SysWatch releases page on GitHub. To update, run the new installer over the old version: your pairing code and settings are kept.

Install on Windows

  1. Download SysWatch_0.2.1_x64-setup.exe and run it.

  2. Windows SmartScreen may say “Windows protected your PC”. Choose More info, then Run anyway. The installer is not code signed yet.

  3. Finish the installer and open SysWatch. It lives in the system tray. Setup lets you pick its language; it starts in your Windows language.

  4. Choose how your phone connects. The first run shows three cards: Local, Cloud by DevLune and Tailscale. Pick one, follow the steps it shows, and it ends on the pairing code.

Choose how your phone connects

SysWatch asks this the first time it opens and never asks for server details. You can change your answer later in Settings, where the same three choices appear as cards.

Not sure? Pick Local if the phone sits near the PC, and Cloud by DevLune if you check your PC from outside and do not want to set up Tailscale. Local and Tailscale need the latest version of both apps.

Now playing, and play, pause and skip from the phone, work in Local and Tailscale mode only. Control from the phone is on by default; switch it off in the desktop app’s Settings, under Media.

Local mode uses one port, 47800. The first time, Windows Firewall asks whether to allow SysWatch on private networks: choose Allow. Local mode is not encrypted, and the 6-character pairing code is the only lock, so use it on networks you trust: your home Wi-Fi, or Tailscale, which encrypts everything itself.

Want local speed away from home? The Tailscale guide takes about five minutes.

Pair the phone

  1. Install SysWatch from Google Play and open it.

  2. On the PC, open Pairing. The first run ends there by itself. A QR code and a 6-character code appear.

  3. On the phone, tap Scan the code on your PC and point it at the QR code.

That is all. The QR code carries the mode, the address and the port, so there is nothing to type.

If it does not connect

What you seeWhat to check
“PC not reachable” in local modePhone and PC are on the same Wi-Fi (not guest Wi-Fi, which isolates devices). Windows Firewall allowed SysWatch. The desktop app is running.
Connects at home, not outsideLocal mode needs Tailscale away from home. See the Tailscale guide.
“Code not found”The PC made a new code. Open Pairing on the PC and scan again.
Stuck on “Paused”The desktop app is paused. Open it and press Resume.
Port already in useChange the port in the desktop app’s Settings, then scan the new QR code.

Still stuck? Open an issue on GitHub or ask on Discord.
