Guide de traduction

Traduire SysWatch

SysWatch parle anglais, allemand, français, espagnol et russe, sur le téléphone comme sous Windows. Vous pouvez ajouter votre langue, ou corriger une formulation dans une langue existante. Aucune programmation : chaque langue tient dans un fichier texte.

Quand une traduction est acceptée, chaque application SysWatch la récupère d’elle-même dans la journée, ou tout de suite depuis Paramètres, Langue, Vérifier. Aucune mise à jour de l’application n’est nécessaire.

Ajouter votre langue

  1. Forkez le dépôt SysWatch sur GitHub (le bouton Fork en haut à droite de la page GitHub).

  2. Dans le dossier translations, copiez en.xml et nommez la copie avec le code de votre langue : hi.xml pour l’hindi, pt-BR.xml pour le portugais du Brésil, ja.xml pour le japonais. La liste des codes de langue les donne dans sa première colonne.

  3. Traduisez le texte entre les balises. Ne touchez à rien de ce qui se trouve entre les chevrons < >.

    <!-- English -->
<string name="pair_scan">Scan the code on your PC</string>

<!-- Your file -->
<string name="pair_scan">अपने पीसी पर कोड स्कैन करें</string>

  4. Ouvrez une pull request. Une vérification se lance d’elle-même et vous dit clairement s’il faut corriger quelque chose. Une fois qu’elle est au vert, la traduction est relue puis acceptée.

Inutile de tout finir d’un coup. Les textes que vous laissez de côté s’affichent en anglais, et l’application indique le taux d’avancement d’une langue. En revanche, ne laissez aucun texte vide : supprimez plutôt la ligne entière.

Un seul fichier sert aux deux applications. Les textes dont le nom commence par desktop_ sont ceux de l’application Windows, les autres ceux de l’application pour téléphone.

Corriger une traduction existante

Modifiez le fichier de la langue (de.xml, fr.xml, es.xml, ru.xml), changez le texte et ouvrez une pull request. Expliquez en une phrase pourquoi la nouvelle formulation est meilleure.

Les règles, cinq en tout

1. Conservez les variables

Des éléments comme %1$s et %2$d sont des emplacements que l’application remplit (un nom, un nombre). Chacun de ceux de l’anglais doit figurer dans votre texte. Vous pouvez les déplacer là où votre grammaire le demande : c’est pour cela qu’ils sont numérotés.

<string name="settings_paired_with">Paired with code %1$s</string>
<string name="settings_paired_with">Gekoppelt mit Code %1$s</string>

Un vrai signe pour cent à côté des variables s’écrit deux fois : %1$d%% s’affiche 47%.

2. Mettez une barre oblique inverse devant l’apostrophe

l\'application, et non l'application. Écrivez &amp; pour & et &lt; pour <.

3. Ne traduisez ni les noms ni les unités

SysWatch, DevLune, CPU, GPU, RAM, Wi-Fi, Tailscale, Google Play, Windows, Android et les unités comme MB, GB, GHz, °C restent tels quels. Les cadrans de veille artistiques (Horizon, Blocks, Bauhaus, Ink, Weave, Bloom, Type, Pixel) gardent aussi leur nom.

4. Les pluriels suivent votre langue

L’anglais a deux formes, one et other. Si votre langue en a davantage (russe, polonais, arabe…), ajoutez celles dont elle a besoin :

<plurals name="settings_import_done">
    <item quantity="one">Импортировано %1$d правило.</item>
    <item quantity="few">Импортировано %1$d правила.</item>
    <item quantity="many">Импортировано %1$d правил.</item>
    <item quantity="other">Импортировано %1$d правила.</item>
</plurals>

5. Restez court et simple

Ce texte s’affiche sur des boutons et de petites cartes, sur un téléphone. Préférez le mot que les gens emploient vraiment au terme soutenu. Pas de tirets longs : utilisez une virgule, deux-points ou un point.

Les lignes qui commencent par <!-- dans en.xml sont des notes pour vous : ce que contient un emplacement, ou l’endroit où le texte apparaît. Inutile de les garder dans votre fichier.

Un texte est à part : language_name est le nom de votre langue, écrit dans votre langue (Deutsch, Español, Русский, हिन्दी). C’est ce que les gens voient dans la liste des langues de l’application.

Vérifier votre fichier avant l’envoi

Cette étape est facultative. Si vous avez Python, lancez depuis le dossier du dépôt :

python scripts/translations.py check translations

La commande affiche ok ou exactement les textes à corriger. La même vérification s’exécute sur votre pull request.

Ce qui se passe après l’acceptation

  • languages.json, dans le dossier translations, est mis à jour automatiquement. C’est la liste que lit l’application.
  • Les applications la consultent une fois par jour. Un téléphone qui utilise votre langue télécharge le nouveau fichier, revérifie chaque texte sur l’appareil (un texte défectueux est ignoré et affiché en anglais : une erreur ne peut donc jamais casser l’application), l’enregistre et l’affiche.
  • Les langues qui ne sont pas intégrées à l’application apparaissent dans la liste des langues avec une icône de téléchargement. Les plus demandées sont intégrées à la version suivante.
