Guide d’installation

Installer SysWatch et associer votre téléphone

SysWatch se compose de deux parties : l’application de bureau sur le PC à surveiller, et l’application Android sur votre téléphone. Installez d’abord l’application de bureau, puis associez le téléphone.

Télécharger l’application de bureau

SysWatch fonctionne sous Windows 10 et Windows 11, 64 bits. Le programme d’installation s’appelle SysWatch_0.2.1_x64-setup.exe et pèse environ 3,5 Mo. L’application mobile demande Android 7.0 ou une version ultérieure.

Télécharger pour Windows Disponible sur Google Play

Toutes les versions et leurs notes de version sont sur la page des versions de SysWatch sur GitHub. Pour mettre à jour, lancez le nouveau programme d’installation par-dessus l’ancienne version : votre code d’association et vos réglages sont conservés.

Installer sous Windows

  1. Téléchargez SysWatch_0.2.1_x64-setup.exe et lancez-le.

  2. Windows SmartScreen peut afficher « Windows a protégé votre ordinateur ». Choisissez Informations complémentaires, puis Exécuter quand même. Le programme d’installation n’est pas encore signé numériquement.

  3. Terminez l’installation et ouvrez SysWatch. L’application se loge dans la zone de notification. La configuration vous laisse choisir sa langue ; par défaut, c’est celle de Windows.

  4. Choisissez comment votre téléphone se connecte. Au premier lancement, trois cartes s’affichent : Local, Cloud by DevLune et Tailscale. Choisissez-en une, suivez les étapes affichées, et vous arrivez au code d’association.

Choisir comment le téléphone se connecte

SysWatch pose la question au premier lancement et ne demande jamais d’adresse de serveur. Vous pourrez changer de réponse plus tard dans les réglages (Settings), où les trois mêmes choix apparaissent sous forme de cartes. L’application de bureau est en anglais : ses libellés sont donc écrits ici tels que vous les verrez.

Vous hésitez ? Choisissez Local si le téléphone reste près du PC, et le Cloud par DevLune si vous consultez votre PC de l’extérieur sans vouloir configurer Tailscale. Local et Tailscale nécessitent la dernière version des deux applications.

La lecture en cours, ainsi que lecture, pause et changement de piste depuis le téléphone, fonctionnent uniquement en mode local et avec Tailscale. Le contrôle depuis le téléphone est activé par défaut ; désactivez-le dans les paramètres de l’application de bureau, rubrique Médias.

Le mode local utilise un seul port, 47800. La première fois, le pare-feu Windows demande s’il faut autoriser SysWatch sur les réseaux privés : choisissez Autoriser. Le mode local n’est pas chiffré, et le code d’association de 6 caractères est le seul verrou : utilisez-le donc sur des réseaux de confiance, comme le Wi-Fi de votre domicile, ou avec Tailscale, qui chiffre tout lui-même.

Envie de la vitesse du mode local hors de chez vous ? Le guide Tailscale prend environ cinq minutes.

Associer le téléphone

  1. Installez SysWatch depuis Google Play et ouvrez-le.

  2. Sur le PC, ouvrez Pairing. Le premier lancement s’y termine de lui-même. Un code QR et un code de 6 caractères s’affichent.

  3. Sur le téléphone, touchez Scanner le code affiché sur votre PC et visez le code QR.

C’est tout. Le code QR contient le mode, l’adresse et le port : il n’y a rien à saisir.

Si la connexion échoue

Ce que vous voyezCe qu’il faut vérifier
« PC injoignable sur ce réseau » en mode localLe téléphone et le PC sont sur le même Wi-Fi (pas un Wi-Fi invité, qui isole les appareils). Le pare-feu Windows a autorisé SysWatch. L’application de bureau est lancée.
Connexion à la maison, pas à l’extérieurHors de chez vous, le mode local a besoin de Tailscale. Voir le guide Tailscale.
« Code introuvable »Le PC a créé un nouveau code. Ouvrez Pairing sur le PC et scannez à nouveau.
Bloqué sur « En pause »L’application de bureau est en pause. Ouvrez-la et appuyez sur Resume.
Port déjà utiliséChangez le port dans les réglages (Settings) de l’application de bureau, puis scannez le nouveau code QR.

Toujours bloqué ? Signalez le problème sur GitHub ou posez la question sur Discord.
